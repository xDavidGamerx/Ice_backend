# ice_backend — Backend/API para ICE Launcher

## Qué es este repositorio (Confirmado)

Este repositorio (`ice_backend`) contiene **únicamente** el backend/API que será consumido por el producto **ICE Launcher**.

- **ICE Launcher (producto)**: el launcher/cliente es un producto externo.
- **Este repo NO incluye el launcher** (por ejemplo, una app Electron) ni su UI.

## Cómo leer la documentación (Quick Start)

1. Lee `AGENTS.md`.
2. Lee `agentsRules.md`.
3. Lee `.skills/ContextSkill.md` para contexto de negocio y producto.
4. Si vas a tocar código o decisiones técnicas, lee `.skills/TechnicalContextSkill.md`.

## Fuente de verdad de contexto

- Contexto de negocio vigente: `.skills/ContextSkill.md`.
- Contexto técnico vigente: `.skills/TechnicalContextSkill.md`.

No existe una fuente alternativa de contexto de negocio fuera de `.skills/ContextSkill.md`.

## Carpeta oficial de skills

La **única** carpeta válida para skills es `.skills/`.
